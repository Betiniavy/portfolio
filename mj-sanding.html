MJ Sanding

A full redesign and rebuild of a flooring services website, focused on trust, clarity, and conversion.

Project Overview

MJ Sanding is a UK-based floor sanding and restoration company. The objective was to replace an outdated, template-driven website with a modern, conversion-focused platform that communicates professionalism and builds trust immediately.

I led the project end-to-end — from UX restructuring and interface design to frontend implementation, deployment, SSL configuration, and DNS migration from Wix to Netlify.

The Problem

The previous website relied on a restrictive template-based platform that limited layout control and weakened the primary call-to-action. Visual proof of completed work was not prioritised, and users encountered friction when attempting to request a quote.

The business required clearer structure, stronger trust signals, improved mobile usability, and full control over hosting and deployment.

Key Improvements

  • Introduced clear hero messaging with immediate primary CTA
  • Reworked content hierarchy to guide users toward quote requests
  • Prioritised real project imagery to strengthen credibility
  • Improved mobile-first layout and responsiveness
  • Migrated to scalable hosting with full deployment control

Process

Discovery & UX Strategy

Analysed competitor websites and identified key trust signals such as experience, insurance, and visual proof. Defined “Request a Quote” as the primary user action.

Interface Design

Developed a clean, neutral visual system reflecting craftsmanship and reliability. Structured content blocks to reduce friction and guide user flow.

Frontend Development

Hand-coded a responsive layout using semantic HTML and modular CSS. Implemented accessible form structure and performance-focused build practices.

Deployment & Migration

Version-controlled development via GitHub and deployed through Netlify with continuous deployment. Migrated the custom domain from Wix, configured DNS records, and provisioned SSL without downtime.

Technical Implementation

  • GitHub version control with CI/CD
  • Netlify automated deployment
  • Custom domain migration and DNS configuration
  • Automatic SSL provisioning
  • Formspree integration for streamlined quote requests

Outcome

The final website is fast, responsive, and structured around conversion. The client now benefits from a scalable, maintainable platform with full deployment control and reduced reliance on restrictive templates.

The streamlined quote flow and improved visual hierarchy strengthen trust, support business growth, and position the brand more professionally online.
