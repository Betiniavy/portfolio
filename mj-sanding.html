Case Study

MJ Sanding

A responsive business website designed and deployed for a UK-based floor sanding and restoration company.

Role: UX Designer & Frontend Developer Tools: HTML, CSS, JavaScript, GitHub, Netlify, Formspree Timeline: End-to-end project
View Live Site

Project Overview

MJ Sanding is a UK-based floor sanding and restoration company. The goal of this project was to design and build a modern, trustworthy website that clearly communicates services and converts visitors into quote enquiries.

I worked across the full lifecycle of the project — from UX decisions and frontend development to deployment, DNS configuration, and launch.

The Problem

The existing setup relied on a template-based website that lacked clarity, strong calls-to-action, and performance optimisation. Visitors had limited visual proof of work, and the quote request journey was not clearly prioritised.

The business needed a website that builds trust quickly, showcases completed work, and makes it easy for customers to request a quote, while remaining easy to maintain long-term.

Existing Website vs Redesigned Solution

The previous website was built using a template-based platform, which limited layout flexibility and made it difficult to prioritise key user actions. Visual proof of work and trust signals were not immediately clear, and the quote request journey required unnecessary steps.

  • Limited control over layout and content hierarchy
  • Weak emphasis on the primary call-to-action
  • Restricted performance and deployment flexibility
  • Clear hero messaging with immediate call-to-action
  • Prominent gallery showcasing completed work
  • Modern deployment setup with automated builds and SSL

Goals & Success Criteria

  • Improve first-impression trust and professionalism
  • Make “Request a Quote” the primary user action
  • Ensure strong mobile usability
  • Optimise performance and SEO readiness
  • Deploy on a scalable, developer-friendly platform

Process

Discovery & UX

Analysed competitor flooring websites and identified key trust signals such as experience, insurance, and visual proof. Defined the primary user action as requesting a quote.

Design Decisions

Used a clean, neutral colour palette to reflect craftsmanship and reliability. Implemented strong hero messaging with an immediate call-to-action and a continuous gallery carousel for social proof.

Development

Hand-coded responsive HTML and CSS with a modular structure. Implemented JavaScript for carousel behaviour and ensured accessible form structure.

Deployment

Version-controlled development via GitHub with continuous deployment through Netlify. Migrated the custom domain from Wix and configured SSL and DNS.

Technical Implementation

  • GitHub version control with main branch CI/CD
  • Netlify deployment with automated builds
  • Custom domain migration from Wix to Netlify DNS
  • Automatic SSL provisioning via Let’s Encrypt
  • Formspree integration for form handling

Challenges & Solutions

Gallery Carousel

Initial carousel behaviour exposed empty space at the end of the image track. This was resolved by implementing continuous looping logic.

DNS Migration

Moving away from Wix required careful DNS configuration. Full DNS control was migrated to Netlify, enabling a cleaner production setup.

Form Routing

Form submissions were initially routed incorrectly. This was fixed by reconfiguring the Formspree account settings.

Final Outcome

The final website is fast, responsive, and easy to maintain. The client can now receive quote requests directly, and the site is hosted on a modern, scalable platform with minimal ongoing overhead.
